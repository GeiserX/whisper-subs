Generation Defaults

Auto-detect reads the audio stream language tags from each file and generates subtitles for every audio language present. If no tags are found, whisper will auto-detect the spoken language. Choose a specific language to force all transcriptions to use it.
Full transcribes all speech (default). Forced Only generates subtitles only for segments where the spoken language differs from the audio track's primary language (e.g., French dialogue in an English movie). Full + Forced generates both files per track. Translation Only skips native-language transcription entirely and only produces English translated subtitles in a single whisper pass — ideal when you only need English subs. Requires a medium or large whisper model (turbo does not support translation). Forced subtitles are saved as .forced.generated.srt and auto-recognized by Jellyfin.

Automation

When enabled, the scheduled task scans your libraries and generates subtitles only for items that do not already have any subtitles. Existing subtitles (embedded or external) are never overwritten.
Select which libraries to include in auto-generation. If none are selected, all libraries will be scanned.
When enabled, music libraries are included in scanning and audio tracks receive .lrc lyrics files generated via whisper transcription. Jellyfin automatically picks up .lrc files placed next to audio files.
Note: Whisper models are trained on speech, not singing. Lyrics accuracy varies widely — clean vocals with minimal instrumentation work best.
When enabled, subtitle generation automatically pauses while any user is playing media and resumes when playback stops. Prevents transcoding stuttering on resource-constrained servers.
When on (recommended), the auto-generation task skips media that already has a usable subtitle in the needed language — including an existing English subtitle when translating. Prevents needlessly re-processing an already-subtitled library.
When on (recommended), forced subtitle tracks (foreign-dialogue-only) do NOT count as 'already subtitled', so full subtitles are still generated.

Subtitle generation

Whisper transcribes the speech it hears, so it can only write a subtitle in the title's own audio language. (Turning audio into English is a separate step — see Translation below.)
Transcribe each title in its own spoken language — a Korean film gets Korean subtitles, an English film gets English. This is the main "generate subtitles" switch. On by default. (A manual single-item "Generate" always transcribes, regardless of this setting.)
When on, existing image-based subtitles (PGS/VOBSUB) count as already-subtitled and the plugin won't generate a text subtitle. Off by default, since image subs can't be searched or edited.
Speeds up the scheduled scan on large libraries: repeat runs skip the per-file re-check for items already known to have subtitles, instead of re-scanning every title each run. An item is automatically re-checked whenever Jellyfin re-saves it (a metadata or subtitle change) or you change a skip setting above. On by default.
Backstop: re-check a remembered item after this many days even if unchanged, so a subtitle deleted outside Jellyfin is eventually regenerated. 0 = rely only on change detection. Default 30.
Forces the next scheduled run to re-check every item from scratch.

Translation to English

English is the only language Whisper can translate into. Use this to give foreign-language titles an English subtitle.
For a title whose audio isn't English and that has no English subtitle, additionally translate it to English. Titles that already have English audio or an English subtitle are skipped automatically — so you only ever fill the gap, never duplicate. Off by default.
Applies only when Subtitle Mode includes Full subtitles (not Forced Only), and is implicit in "Translation Only" mode. Uses whisper's built-in --translate — no external services.

Subtitle Timing

Uses whisper.cpp's built-in Silero voice-activity detection so subtitles start when speech actually begins, instead of during the silence before a line. Recommended.
The small (~865 KB) VAD model is downloaded automatically on first use. Applies only to locally-generated subtitles (whisper-cli), not the remote API or forced subtitles. When enabled, it replaces the FFmpeg silence-detection pass below.
Older energy-based timing fix that snaps each subtitle's start to when the line is spoken, using an extra FFmpeg silence-detection pass. Used only when "Use speech detection (VAD)" above is off — VAD does this more reliably. Leave on as a fallback.
Applies only to locally-generated subtitles (whisper-cli), not the remote API or forced subtitles.
If subtitles still appear early with "Use speech detection (VAD)" enabled, turn this on to also run the speech-alignment pass above on top of VAD. VAD improves transcription but doesn't always correct whisper's tendency to start a line slightly early; this snaps those starts forward — it only ever moves a line later, never earlier (though on coarse audio the energy-based detector may push a few starts slightly late). Off by default. Requires "Align subtitles to speech" to be on.
Applies only to locally-generated subtitles (whisper-cli), not the remote API or forced subtitles.
VAD tuning (advanced)
Which Silero VAD model whisper-cli uses. v5.1.2 is the default; v6.2.0 is newer. Changing this downloads the selected model on the next run.
Speech-probability cutoff, 0–1. Lower catches quieter speech but adds false positives. Default 0.5.
Minimum speech-segment length in milliseconds; shorter segments are discarded. Default 250 ms.
Minimum silence in milliseconds that splits two subtitles. Higher values group sentences together. Default 100 ms.
Maximum subtitle-segment length in seconds; longer speech is auto-split. Empty = unlimited. ~30 avoids timestamp drift on long takes.
Padding in milliseconds added to each side of a speech segment so word edges aren't clipped. Default 30 ms.
Audio overlap in seconds carried between consecutive segments to avoid clipping words at boundaries. Default 0.1 s.
These apply only when 'native VAD' is enabled. Leave a field empty to use whisper.cpp's default. A matching flag placed in Custom Whisper Arguments overrides the value set here.
Keeps subtitles in sync when a file's audio doesn't start exactly at 0:00. Recommended.
Applies only to locally-generated subtitles (whisper-cli), not the remote API or forced subtitles.
Remote Whisper API (Optional)
URL of an OpenAI-compatible Whisper API (e.g. faster-whisper-server, Speaches). When set, audio is sent to this server instead of running whisper locally. Leave empty to use local whisper-cli.
Model identifier to request from the remote API. For Speaches: a Hugging Face model ID. For OpenAI: "whisper-1".
Bearer token for OpenAI-compatible servers that require authentication (OpenAI, hosted Speaches, pfrankov/whisper-server with auth, etc.). Sent as Authorization: Bearer <key>. Leave empty for unauthenticated local servers.
Worker Pool (Optional / Advanced)
Leave this empty to transcribe on this server (the default). Add remote OpenAI-compatible Whisper endpoints to spread the backlog across machines/GPUs — see the worker/ image in the repo.
Keep this server's own whisper-cli in the pool. Only matters once you add remote workers below — with none, this server always does the work. On by default.
Advanced / Manual Install
Absolute path to the whisper-cli binary (e.g., /opt/whisper/whisper-cli). Leave empty to search PATH.
Absolute path to the Whisper model file. You can type a path or select from detected models below.
Number of CPU threads for whisper inference. 0 = whisper default (4). Set to your CPU core count for faster transcription.
Extra arguments appended to whisper-cli (space-separated). Only applies to local whisper-cli, not the remote API. Useful for timing improvements (e.g., --max-len 47 --split-on-word) or tuning (--beam-size 8). Flags managed by the plugin (model, language, output format) are automatically blocked.

Subtitle Requests & Priority

Let your users request subtitles from the item page, and control the order the queue works through everything. Priority is expressed as named tiers — Critical › High › Medium › Low › Background — and the tier is always assigned by the server from who asked, never from the browser.
Adds a “Request Subtitles” entry to the item menu for non-admin users. Off by default — when off, nothing changes and the plugin stays admin-only. Requests are de-duplicated, rate-limited and (unless auto-approved) held for your approval.
When on, a user request goes straight onto the queue at the user tier. When off (default), requests wait as Pending and spend no CPU until you approve them below. With auto-approve on, size the limits below together — a single user's worst case is Max active requests × Max items per request transcriptions queued at once.
Priority for what you queue with Generate / Generate-all. Default High.
Priority for what your users request. Default Medium (above the background sweep, below your admin requests).
Priority of the “fill every gap” auto-generation sweep. Default Background — it runs whenever the request queue is idle.
User request limits (anti-abuse)
How many requests one user may make within the rolling window below. 0 = unlimited. Default 5.
The window the quota above is measured over. Default 24.
How many pending + queued requests a user may have at once. 0 = unlimited. Default 3.
Cap on how many episodes a single season/show request may expand to. Default 200.
Cap on total user requests pending/queued across everyone. 0 = unlimited. Default 500.
